### 🌍 Open Source

Worked with the Chromium team to rebuild the **Chrome Bookmarks Manager tree view**, migrating the UI from Polymer to Lit.

* Built recursive tree rendering for bookmarks.
* Added accessibility improvements including keyboard navigation and screen-reader support.
* Added TypeScript tests with full coverage for the new functionality.
* Worked through code reviews and design discussions with Chromium maintainers.

Also contributed to **Chromium DevTools** and other open-source projects before GSoC.
